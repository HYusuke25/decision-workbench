# 意思決定ワークベンチ

複数の評価基準をもとに、基準の重み付けと代替案（選択肢）の順位付けを行う、多基準意思決定（MCDM）の支援ツールです。ブラウザだけで動き、インストールは要りません。

**公開URL：** https://hyusuke25.github.io/decision-workbench/

## できること

| 工程 | 内容 |
|---|---|
| 1. 基準と代替案 | 評価基準（単位・次元・便益／費用の方向）と代替案を登録し、決定行列を入力 |
| 2. 基準の重み付け | 複数の手法で重みを計算・比較し、評価に使う重みを選択 |
| 3. 代替案の評価 | 4つの手法で順位付けし、手法間の順位の一致を確認 |
| 4. 感度分析 | 基準の重みを変えたときの順位の変化と、1位が入れ替わる重みの範囲を確認 |
| 手法の選び方 | 質問に答えると、目的に合う手法を提案 |

### 実装している手法

- **重み付け**
  - DEMATEL：基準間の因果関係（中心度 D+R・原因度 D−R）と影響関係マップ
  - DANP（DEMATEL型ANP）：次元（基準のグループ）対応版。次元を設定しない場合は単一クラスタとして計算
  - AHP：固有ベクトル法・幾何平均法、整合比 CR、整合性を崩している比較の指摘
  - エントロピー法、CRITIC：決定行列から求める客観的な重み
  - 組合せ：主観的な重み（DANP／AHP／直接入力）と客観的な重み（エントロピー法／CRITIC）の積
- **代替案の評価**
  - 加重和（WSM）、TOPSIS、VIKOR（妥協解と条件 C1・C2）、PROMETHEE II（通常型・線形型の選好関数）
  - 手法間の順位比較（Spearman の順位相関）
- **複数回答者の集約**：DEMATEL は算術平均、AHP は幾何平均

### 計算の検証

- DANP（単一クラスタ）：Python（numpy）で書いた既存の実装と、同じ入力で重みが一致（誤差 1e-8 未満）
- DANP（次元あり）・TOPSIS：numpy による独立実装と一致
- AHP：Saaty の 3 基準の数値例（重み ≈ 0.637 / 0.258 / 0.105、CR ≈ 0.033）を再現

## 使い方

1. 公開URLを開きます。最初はサンプル（業務用ノートPCの選定）が入った状態で開きます。
2. 左のメニューの順に、基準・代替案の入力 → 重み付け → 評価 → 感度分析と進みます。
3. 入力内容はブラウザに自動保存されます。他の人に渡すときは「案件を保存」で JSON ファイルにし、相手は「案件を開く」で読み込みます。

入力したデータはどこにも送信されません。計算と保存は、使う人のブラウザの中だけで行われます。
